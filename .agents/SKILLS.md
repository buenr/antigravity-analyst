# Data Scientist / Analyst Skill Catalog

This catalog summarizes the Antigravity skills mounted for this agent. Runtime-discoverable skills live in `.agents/skills/<skill-name>/SKILL.md`.

Package installation tiers and bootstrap commands are defined in `.agents/AGENTS.md` and `.agents/bootstrap_packages.sh`.

- `dataset-profiler`: inspect files, schemas, quality issues, missingness, duplicates, and outliers.
- `statistical-analysis`: perform EDA, statistical comparisons, uncertainty-aware interpretation, and practical summaries.
- `ml-modeling`: build leakage-aware supervised learning workflows with baselines and appropriate metrics.
- `forecasting`: analyze time-series data with chronological validation, backtesting, trend, seasonality, and caveats.
- `deliverable-builder`: create final reports, charts, tables, and exports in `./outputs/`.
